# Proyecto Final Investigación de Operaciones II

Agente IA para resolver problemas de Programación Entera Mixta.

## Tecnologías

- Python
- PuLP
- Streamlit
- Gemini API
- UV
- Ruff

## Instalación

```bash
uv sync
```

## Configuración

Crear un archivo `.env` en la raíz del proyecto:

```env
GEMINI_API_KEY=tu_api_key
```

## Ejecución

```bash
uv run streamlit run app/main.py
```
